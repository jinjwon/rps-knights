# RPS Knights — Unity Web 프로토타입

Unity 6 기반 웹 게임 프로젝트다. 화면 버튼으로 손 모양을 고르고, 양쪽 주먹이 “가위… 바위… 보!”에 맞춰 흔들린 뒤 상대의 무작위 손과 동시에 공개된다. 결과를 적용한 기본 3D 결투까지 한 라운드로 이어진다.

## 열기

1. Unity Hub에서 이 `unity` 폴더를 프로젝트로 추가한다.
2. Unity `6000.0.65f1` 또는 같은 Unity 6 LTS 계열로 연다.
3. Web Build Support 모듈이 없다면 Hub의 해당 Editor 설정에서 추가한다.
4. Play 버튼을 누른다. 빈 장면에서도 프로토타입 UI가 자동 생성된다.

## 조작

- 화면 버튼 또는 숫자 `1`: 가위
- 화면 버튼 또는 숫자 `2`: 바위
- 화면 버튼 또는 숫자 `3`: 보
- 결투 이동: `W` `A` `S` `D`
- 결투 공격: `Space` 또는 화면 공격 버튼

## 웹 빌드

Unity 메뉴에서 `RPS Knights > 웹 빌드 만들기`를 누른다. 결과는 `unity/Builds/Web`에 생성되며 Git에는 포함되지 않는다.

현재 결투는 기본 도형 기사, 체력 100, 45초 제한, 근접 공격과 간단한 봇으로 구성된다. 가위바위보 패자는 결투 시작 후 4초 동안 이동속도가 감소한다. 특수 스킬·총 변형·총알 막기는 다음 구현 범위다.
